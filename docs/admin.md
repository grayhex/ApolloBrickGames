# Настройка коллекции и Cloudflare

Прямой адрес — `/admin`. Ссылки в пользовательском интерфейсе нет. Админка настраивает четыре складные Apollo, E‑88, Apollo B0202 и универсальный Brick Game. Alibaba и Mini Brick Game в каталоге устройств пока остаются экспонатами без игр и в конфигурацию версии 1 не входят. Админка редактирует набор и порядок игр, выбранную при включении игру, подмножество её вариантов, доступные цвета и основной цвет каждого корпуса, а также цвет миниатюры модели в каталоге устройств (`thumbShell`: по умолчанию белый; у Apollo — из их палитры, у универсального Brick Game — белый и четыре варианта универсального корпуса; поле необязательное, старые документы читаются как белый). Для Mario сохранён оригинальный экран: действующая игра и два обозначенных будущих слота. Загрузка однобитной мелодии — отключённая заглушка. Карточка «Общие» задаёт язык интерфейса по умолчанию (`language`: `ru` или `en`, поле необязательное; старые документы читаются как `ru`). Он применяется только посетителю, который ещё сам не переключал язык кнопкой RU/EN: выбор посетителя хранится локально и имеет приоритет.

## Где лежат настройки

1. `src/config/default.json` — проверяемый, версионируемый резервный набор в репозитории.
2. Cloudflare Durable Object `ConfigurationStore`, привязка `CONFIG` — общая опубликованная конфигурация.
3. `/api/config` возвращает её всем посетителям. Если ещё ничего не опубликовано, возвращается файл из репозитория.

В браузере нет собственного скрытого набора игр из localStorage. При недоступном API используется файл из сборки. Обычные пользовательские настройки клавиатуры, звука и цвета остаются локальными; выбранный игроком цвет имеет приоритет над основным цветом из админки, если он доступен у корпуса.

После публикации новая конфигурация применяется при следующем открытии/обновлении коллекции. Текущая партия не прерывается. Конфигурация не кэшируется HTTP. Сервер проверяет весь документ до записи; одна ошибочная игра, режим или цвет отклоняет всю публикацию.

## Включение сохранения

`wrangler.jsonc` содержит Worker, привязку Assets, Durable Object и миграцию SQLite `config-v1`. При обычном деплое Cloudflare создаёт нужное хранилище автоматически. Отдельная база D1 или namespace KV не требуется.

В Cloudflare Dashboard → Workers & Pages → **crocodilemario** → Settings → Variables and Secrets добавьте **секрет** `ADMIN_TOKEN` — случайную строку длиной не менее 32 символов. Не добавляйте её в Git, переменные `VITE_*`, JSON или сообщения. Затем примените изменение/деплой в панели.

Откройте `/admin`, измените набор и нажмите «Опубликовать», введя ключ. Ключ остаётся только в поле открытой вкладки; после успешной записи поле очищается. Без секрета API записи отвечает 503, а сайт и чтение настроек работают. Неверный ключ — 401, чужой Origin — 403. Это общая секретная авторизация администратора; персональные учётные записи и Cloudflare Access не настроены.

Путь `/admin` не является защитой: защита находится в `PUT /api/admin/config`. Нет CORS-доступа к записи. Запрос ограничен 64 КиБ; API не принимает новые файлы музыки, HTML или исполняемый код.

## Одновременное редактирование

Каждая публикация увеличивает ревизию. Запись выполняется транзакцией Durable Object. Если другая вкладка уже опубликовала изменения, сервер отвечает 409. Черновик остаётся на экране: скачайте его перед загрузкой актуальной версии, затем повторите нужные изменения.

## Репозиторий, экспорт и откат

«Скачать JSON» создаёт `default.json`. Импорт проверяет тот же формат, что сервер. Чтобы опубликовать через Git, замените `src/config/default.json`, пройдите CI и выполните обычный деплой.

**Если в Durable Object уже опубликованы настройки, они имеют приоритет над файлом после любого деплоя.** Для перехода к файлу нажмите «Вернуть набор из репозитория», проверьте его и опубликуйте. Эта операция создаёт новую ревизию, не удаляет хранилище. Для отката импортируйте ранее экспортированный JSON и опубликуйте его.

Сохранённые рекорды привязаны к игре и режиму, а не к позиции в меню. Перестановка не теряет рекорд. Отсутствующая игра не удаляет её прошлый рекорд.

## Локальная проверка

```sh
npm ci
npm run typecheck
npm run lint
npm test
npx wrangler dev
```

Wrangler собирает Assets и запускает настоящий локальный Worker с Durable Object. Для локального сохранения задайте тестовый `ADMIN_TOKEN` в игнорируемом `.dev.vars`. Не используйте производственный ключ в тестах.

`npx wrangler deploy --dry-run` проверяет сборку Worker и привязки без публикации. Браузерные проверки API/UI дополняются тестами серверной авторизации, валидации и конфликтов ревизий.

Редактор уровней открывается из карточки **Crocodile Mario**. Для остальных моделей ссылки на редактор нет. Начальный цвет каждого нового посещения берётся из опубликованной конфигурации; настройки управления игрока его не переопределяют.

## Универсальный Brick Game

Пятая карточка в студии управляет закреплёнными играми универсальной приставки. В поставляемой конфигурации ей закреплены все 55 игр каталога, кроме Mario (в том числе пары-синонимы), поэтому порядок в меню задаёт `default.json`, а автоматический список остаётся запасным. Дополнительно она автоматически получает все реализованные матричные игры, не назначенные ни одной Apollo. Если такую игру назначить Apollo, она исчезнет из автоматического списка; закреплённые игры остаются. Автоматический список пересчитывается при загрузке сайта. Экспонаты Alibaba и Mini Brick пока не имеют меню.

Старые конфигурации версии 1 с четырьмя Apollo совместимы: настройка Brick Game добавляется при чтении, существующие меню и цвета сохраняются. У универсальной модели два цвета корпуса — `gray` и `black`; в админке можно выбрать доступные версии и цвет по умолчанию.

## Реальные E‑88 и B0202

У B0202 назначается игра целиком: базовый `entryId` и вложенный массив `variants`. Флажки модификаций находятся внутри карточки; `defaultEntry` всегда базовый, а в игре модификации выбираются MODE. У E‑88 восемь самостоятельных карточек, в том числе четыре тетриса, без вложенных модификаций. Прежние пять семейств E‑88 разворачиваются при чтении; порядок и выбранный старт сохраняются. Миграции не переписывают сохранённый документ и revision. Палитры оригиналов: E‑88 — gray, B0202 — black. Восстановление оригинального набора возвращает все доступные пункты.

У универсального Brick Game доступны серый, чёрный, светлый прозрачный (`clear`) и тёмный прозрачный (`smoke`) корпуса. `shellPaletteVersion:2` фиксирует обновлённую палитру: прежний стандартный набор gray/black расширяется однократно при нормализации, последующие ограничения администратора сохраняются. Плата под прозрачным пластиком — декоративная иллюстрация.

Старый опубликованный config версии 1 дополняется при чтении, без сброса данных и без изменения revision. При следующем сохранении добавленные модели записываются обычной транзакцией. [Подробности и локальная проверка SQLite Worker](devices/e88-b0202.md).
