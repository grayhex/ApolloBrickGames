# Демонстрационный проект редактора

Всё здесь **искусственное**: картинка нарисована программой, а не снята с устройства, и не является оригинальным кадром или уровнем.
Пример нужен, чтобы попробовать редактор и проверить калибровку.

| Файл | Что это |
| --- | --- |
| `artificial-reference.png` | Сгенерированный «снимок экрана» 640 × 360 с перспективой. Цветные кружки — углы игровой области: красный — верхний левый, зелёный — верхний правый, синий — нижний правый, жёлтый — нижний левый |
| `artificial-room.crocodile-project.zip` | Проект редактора: карта 13 × 6, три пометки (`?` / `≈` / `✓`), калибровка и копия картинки |
| `artificial-room.json` | Игровой JSON той же карты (с пометками в `marks`), проходит валидатор игры |

Открыть: `#/editor` → «Импорт…» → выберите `.zip` (или добавьте `artificial-reference.png` как новое фото и отметьте четыре угла по цветным кружкам).
Файлы создаёт тест `tests/editor/demoProject.test.ts`; пересоздать: `UPDATE_FIXTURES=1 npx vitest run tests/editor/demoProject.test.ts`.
