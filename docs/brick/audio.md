# Синтез звуков Brick Game

У «Часов+99», «Морского боя» и «168 в 1 танк» эффекты и короткие мелодии создаются Web Audio, без загрузки или декодирования записей. Mario сохраняет отдельную звуковую дорожку и необязательный ремастер.

`src/audio/brickPhrases.ts` — тоновая транскрипция прежних звуков n0Live/BrickGame (MIT), версия `6f58b1069cdddc1b7d1a3192783b9de9161cd0dc`, каталог `src/sounds`. Исходники доступны в репозитории донора; копии M4A из приложения удалены. Авторство и лицензия сохранены в [THIRD_PARTY.md](../THIRD_PARTY.md).

Это приближение к прежним эффектам, не подтверждённая прошивка Apollo. Частоты и ритм подобраны по спектральным измерениям записей; шум записи и компрессии не воспроизводится. У мелодий сохранён приблизительный строй донора, без принудительной настройки на стандартные ноты.

| Сигнал | Синтез |
| --- | --- |
| select | 1110 → 990 → 825 → 1560 Гц, четыре шага по 45 мс |
| move / turn | подъём 620–1450 Гц за 130 мс / спад 1350–800 Гц за 65 мс |
| bonus / remove_line | подъём около 620–1400 Гц за 0,70–0,73 с |
| fall / hit_cell | быстрое детерминированное переключение частоты, 0,20–0,23 с |
| fall_super | удар и спад 2100–1050 Гц |
| kaboom | быстрое переключение частоты с понижением центра за 1,04 с |
| start / win / game_over / tetris | последовательности частот и пауз в `brickPhrases.ts` |

Один прямоугольный генератор на эффект, общая громкость как у пищалки Mario. Огибающая 2–4 мс сглаживает щелчки на границах нот. Музыкальный сигнал имеет приоритет над движением; пауза, выключение, mute и смена игрушки сразу отключают выход и отменяют запланированные ноты. Первая нота запускается по жесту без ожидания сети. Simon и Dance используют отдельные синтезированные тоны площадок.

Проверки: `tests/audio/brick.test.ts` — расписание, частоты, приоритеты, жизненный цикл, отсутствие сетевых запросов; браузерные проверки — `tests/smoke/synth-controls.spec.ts`.
