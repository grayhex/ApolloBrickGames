# Crocodile Mario — комплект LCD-графики

Реконструкция по двум предоставленным фотографиям. Разрешения недостаточно для достоверного восстановления мелких контуров и электрического разбиения дисплея. Это подготовленные для разработки спрайты, не извлечённые оригинальные ресурсы.

## Главный принцип

Одна общая ячейка: **128 × 112 px**, центр **(64, 56)**. Все спрайты ячейки сохраняют этот холст, включая прозрачные поля. Не обрезайте их по непрозрачным пикселям: иначе собьётся совмещение.

- `cell_player`: голова/кепка, торс, руки и ноги персонажа.
- `cell_obstacle`: сегменты вокруг персонажа; центральная маска выключена.
- `cell_all_on`: обе маски включены одновременно, с сохранением LCD-зазоров.
- `cell_ghost`: все электроды с прозрачностью 7,5%, для имитации выключенного LCD.
- `cell_empty`: полностью прозрачная ячейка.
- `cell_object`: небольшая метка/предмет, различимый на первом фото; назначение не установлено.

**Препятствие не является непрозрачным прямоугольником с рисунком цвета фона.** Вырез под персонажа и разделительные зазоры действительно прозрачны. Маски персонажа и препятствия геометрически не пересекаются. Их можно независимо включать на одних координатах.

На снимках нельзя надёжно установить, горит ли центральная группа также внутри заполненного препятствия. Основной вариант строго следует описанному принципу: персонаж в препятствии выключен. Дополнительно сохранён `cell_all_on`, который позволяет сравнить полное заполнение со снимками. В HTML есть соответствующий переключатель.

## Содержимое

`png/1x`, `png/2x`, `png/4x` — PNG RGBA на прозрачном фоне. Размер игровой ячейки соответственно 128×112, 256×224 и 512×448. Цвет активных сегментов #303A30.

`svg` — масштабируемые изображения. `svg/lcd-symbols.svg` — библиотека SVG-symbol. Отдельные файлы самодостаточны.

`svg/segments` — отдельные части персонажа и окружающих полей. У каждой части тот же viewBox 128×112. Это удобное программное разбиение, не оригинальные аппаратные адреса.

`masks` — отдельные части и чёрные альфа-маски основных состояний. Для перекраски используйте альфа-канал; не извлекайте прозрачность из яркости RGB.

`atlas/lcd_atlas.png` + `lcd_atlas.json` — не обрезанный атлас с точными координатами кадров и полями 4 px. Формат RGBA; без поворота спрайтов. Масштаб атласа 1x.

`digit_0`…`digit_9`, `digit_minus`, `digit_blank`, `digit_ghost`, `dot` — HUD. Цифра занимает 64×104 px. Формы семисегментных цифр восстановлены по фотографии, а не взяты из системного шрифта.

`life`, `lives_3` — индикаторы жизней, основанные на том же персонаже.

`backgrounds/lcd_plain.png` — однотонный LCD. `lcd_texture.png` — очень слабая текстура, только для демонстрации. Не запекайте фон в игровые спрайты.

`screens/reference_1_obstacle.png` и `reference_2_obstacle.png` — примеры с выключенным персонажем внутри препятствий. Версии `_all_on` показывают также центральную группу. `layouts` — примерные композиции 13×6 и 13×8 из фотографий; это не установленное правило игры и не жёсткая привязка графики к размеру поля.

`preview.png` — обзор комплекта; `hud-preview.png` — цифры и индикаторы. `preview.html` — автономное интерактивное сравнение слоёв; откройте локально в браузере. Интернет не нужен.

## Отрисовка

1. Отрисуйте фон LCD.
2. Необязательно: отрисуйте `cell_ghost` в каждой позиции поля.
3. Поверх отрисуйте `cell_player` либо `cell_obstacle`, сохранив общий центр.
4. `cell_all_on` используйте только для состояния с обеими включёнными группами.

Пример расположения по левому верхнему углу: `x = boardX + column * 128`, `y = boardY + row * 112`. Масштаб должен быть одинаковым для всех слоёв и для шага сетки. Вырезы отображаются цветом фона автоматически благодаря прозрачности.

Для дополнительной имитации оптики LCD добавляйте слабую тень и размытие на этапе рендеринга, а не изменяйте исходные маски. Анимационные позы, противники и прочие неразличимые на фото элементы в этот набор не добавлялись.

## Проверки

Совмещение масок, прозрачность, отсутствие пересечений, размеры PNG и прямоугольники атласа проверены программно. У всех SVG задан viewBox. Контуры остаются приблизительной реконструкцией.
