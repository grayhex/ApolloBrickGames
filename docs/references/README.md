# Каталог референсов

Здесь учитываются фотографии и кадры оригинального устройства: что на них видно и чего не хватает.

> **Важно.** Часть снимков (список ниже) владелец показывал в чате; в репозитории лежат только те, что в
> `docs/references/raw/`. Исходники владелец добавляет в `docs/references/raw/` (оригиналы без изменений);
> выправленные и обрезанные фрагменты кладутся в `docs/references/crops/`. В рантайме фотографии не используются.
> Видео в Git не добавляем.

## Структура

```text
docs/references/
  README.md   этот каталог источников
  raw/        исходные снимки без изменений
  crops/      выправленные / обрезанные фрагменты для работы
```

## Что нужно добавить для восстановления графики (issue #2)

Минимум, без которого соответствующий элемент остаётся блокером:

| Нужный референс | Для чего | Статус |
| --- | --- | --- |
| Весь **включённый** экран, примерно перпендикулярно камере, со всеми краями и верхними индикаторами | сетка поля, пропорции ячейки, отступы HUD, число столбцов/строк | 🟡 спрайты и раскладки владельца (`raw/`) есть; число строк (6 или 8) по фото не установлено |
| Крупный резкий фрагмент **героя** на пустом фоне, лучше в нескольких состояниях/направлениях | силуэт героя, различимые положения | 🟡 `cell.player` из пакета владельца (приблизительно); поз и зеркала нет |
| Крупный фрагмент **блока земли** и соседних ячеек | внутренний рисунок блока и интервалы | 🟡 `cell.obstacle` из пакета владельца (приблизительно) |
| Верхняя строка: цифры и значки жизней крупно | форма цифр и индикатора | 🟡 цифры 0–9, «−» из пакета владельца; назначение значков не установлено |
| Выключенный/пустой экран | цвет подложки, неактивные сегменты | 🟡 `cell.ghost` (7,5 %) из пакета владельца; ф5 (перспектива) |
| Серия кадров прыжка | отличается ли героя в прыжке | ⛔ нет |
| Корпус целиком: красный и белый | цвета лицевой панели, рамки и рисунка | 🟡 синий — `raw/blue.png`; красный — фото в чате; белого отдельного снимка нет |

Подробности по восстановленным элементам и их статусу — в [../visual-spec.md](../visual-spec.md).

## Логотип

Логотип «Crocodile Mario» (надпись и персонаж) предоставлен отдельно и лежит в [../brand](../brand/README.md).
Это фирменная иллюстрация, а не снимок LCD: для восстановления спрайтов она не подходит, но подтверждает облик персонажа
(шляпа с широкими полями, круглая голова с зубастой улыбкой, поднятый кулак, шейный платок, большие ботинки).
