# Каталог референсов

Здесь учитываются фотографии и кадры оригинального устройства: что на них видно и чего не хватает.

> **Важно.** Снимки, о которых говорится ниже, были показаны владельцем в чате с ассистентом.
> **В репозитории их нет**, и другой исполнитель не может считать, что у него есть доступ к вложениям.
> Владелец добавляет исходники в комментарии к issue или в `docs/references/raw/` (оригиналы без изменений);
> выправленные и обрезанные фрагменты кладутся в `docs/references/crops/`. В рантайме фотографии не используются.
> Видео в Git не добавляем.

## Структура

```text
docs/references/
  README.md   этот каталог источников
  raw/        исходные снимки без изменений
  crops/      выправленные / обрезанные фрагменты для работы
```

## Учёт исходников

Для каждого файла в `raw/` добавляйте строку: имя, назначение, источник (ссылка на комментарий), состояние экрана,
известные ограничения.

| Файл | Назначение | Источник | Состояние | Ограничения |

## Что нужно добавить для восстановления графики (issue #2)

Минимум, без которого соответствующий элемент остаётся блокером:

| Нужный референс | Для чего | Статус |
| --- | --- | --- |
| Весь **включённый** экран, примерно перпендикулярно камере, со всеми краями и верхними индикаторами | сетка поля, пропорции ячейки, отступы HUD, число столбцов/строк | ⛔ нет подходящего: ф1–ф4 с перспективой и без резкости |
| Крупный резкий фрагмент **героя** на пустом фоне, лучше в нескольких состояниях/направлениях | силуэт героя, различимые положения | ⛔ нет: на ф1–ф4 герой слишком мелкий |
| Крупный фрагмент **блока земли** и соседних ячеек | внутренний рисунок блока и интервалы | 🟡 частично: ф4 показывает рисунок, но не резко |
| Верхняя строка: цифры и значки жизней крупно | форма цифр и индикатора | 🟡 частично: ф4 (цифры 0, 1, 9), ф1–ф3 (0, 1, 2, 3) |
| Выключенный/пустой экран | цвет подложки, неактивные сегменты | 🟡 ф5 (перспектива) |
| Серия кадров прыжка | отличается ли героя в прыжке | ⛔ нет |

Подробности по восстановленным элементам и их статусу — в [../visual-spec.md](../visual-spec.md)
(появится вместе с задачей #2).
