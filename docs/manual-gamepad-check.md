# Ручная проверка геймпада

Автоматические тесты используют **подставной** провайдер `navigator.getGamepads()` (юнит-тесты
`tests/input/gamepad.test.ts`, `tests/app/hub.test.ts` и браузерный smoke-тест). Они проверяют логику
адаптера, но не реальный контроллер, ОС и драйвер. Эту проверку выполняет владелец с настоящим устройством.

Условия: страница открыта по **HTTPS или с localhost** (Gamepad API недоступен на обычном http по сети);
в Chrome/Edge геймпад «виден» странице только после первого нажатия кнопки; распознавание и `mapping`
зависят от браузера и ОС.

## Чек-лист

Отметьте результат: ✅ работает, ❌ не работает (опишите), — не проверялось.

- [ ] До нажатия кнопки под игрой написано «Нажмите кнопку на геймпаде»; после нажатия — «активен: …».
- [ ] Само нажатие, активировавшее геймпад, **не** запускает игру и не даёт прыжка.
- [ ] Start на геймпаде запускает игру, ещё раз — ставит на паузу, ещё раз — продолжает.
- [ ] Крестовина влево/вправо и левый стик влево/вправо двигают героя; лёгкое дрожание стика около центра
      не двигает героя; у порога направление не «мигает».
- [ ] Нижняя лицевая кнопка — прыжок; удержание не приводит к повторным прыжкам до нового нажатия.
- [ ] Левая лицевая кнопка — огонь (в техническом демо).
- [ ] Движение + прыжок + огонь одновременно работают.
- [ ] Отключение шнура/Bluetooth **во время игры**: игра на паузе, подсказка «Геймпад отключён», герой не дёргается.
- [ ] Подключение обратно с **зажатой** кнопкой прыжка/огня и явное продолжение: нет случайного прыжка/выстрела,
      пока кнопку не отпустили и не нажали заново.
- [ ] Переключение на другую вкладку и возврат: игра на паузе, продолжение только явное, без скачка героя.
- [ ] «Настройки…»: переназначение кнопки геймпада работает и переживает перезагрузку страницы;
      «Сбросить геймпад» возвращает стандартную раскладку; порог стика меняет поведение.
- [ ] Если у контроллера нестандартный `mapping`: видна подсказка «назначьте кнопки в Настройках», автоматической раскладки нет.
- [ ] Навигация по окну «Настройки» геймпадом: вверх/вниз — выбор, нижняя кнопка — нажать, правая (`buttons[1]`) — закрыть.
