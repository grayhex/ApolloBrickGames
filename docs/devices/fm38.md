# Brick Game FM-38

Корпус и печать взяты из графики, предоставленной владельцем в `docs/research/fm-38.zip`; локальные ресурсы находятся в `public/devices/fm38`. Они предназначены для этого проекта. Фото и объяснение владельца — источник управления и структуры устройства; подтверждённого ROM FM-38 нет.

Включение сразу запускает демонстрацию тетриса. LEFT выбирает уровень, RIGHT — скорость, DOWN — A/B. START начинает новую партию с выбранными параметрами, затем ставит её на паузу и продолжает. ROTATE поворачивает фигуру, MELODY переключает мелодии (подтверждено владельцем). Громкость и выключение звука — в пульте. Модель не складывается, доступно увеличение экрана.

До расшифровки записи оригинала владелец согласовал временный синтезированный набор: «Коробейники» и «Ода к радости» Бетховена. Это адаптации общественного достояния, не заявление о репертуаре прошивки. Выбранная мелодия играет один раз при старте; MELODY меняет её без сброса партии. Звуки движения, поворота и посадки — чистые синтезированные сигналы B-S96. Пауза останавливает музыку, продолжение сохраняет позицию.

A использует обычные тетромино, B — усложнённый набор существующего ядра Pentix из 26 фигур размером 3–5 клеток. Точный набор B, тайминги и алгоритм демонстрации оригинала пока неизвестны и являются приближением. Шкала фруктов переиспользуется из B-S96 по подтверждению владельца. Демонстрационные очки не сохраняются; локальные рекорды A/B изолированы от других моделей. Общий рейтинг для этой реконструкции пока не подключён.
