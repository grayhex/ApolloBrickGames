# Проверка производительности интерфейса

Замер в Chromium 154, viewport 1440 × 900, Vite dev server, reduced motion. Для каждой игрушки: 2 секунды с выключенным питанием, затем включение, завершение интро, старт и ещё 2 секунды без ввода. Подсчитывались вызовы `fillRect`, `clearRect`, `drawImage` на игровом Canvas и записи MutationObserver по странице. Это измерение объёма работы, а не FPS или времени CPU.

| Сценарий | Canvas до → после | DOM-мутации до → после |
| --- | --- | --- |
| Mario, выключен | 120 → 0 | 960 → 0 |
| Часы+99, выключены | 121 → 0 | 363 → 0 |
| Морской бой, выключен | 121 → 0 | 363 → 0 |
| Mario, игра | 15 740 → 15 477 | 1 214 → 252 |
| Часы+99, игра | 9 801 → 243 | 484 → 120 |
| Морской бой, игра | 35 400 → 885 | 480 → 120 |

У тетриса число учтённых операций рисования в этом сценарии сократилось примерно на **97,5%**. Числа зависят от частоты кадров и текущей фигуры; это не утверждение об аналогичном росте FPS. Активный Mario сохраняет покадровый рендер анимаций. Игровая симуляция, звук и опрос геймпада продолжают работать в прежнем темпе.

Что изменено:

- Выключенный экран очищается один раз. Изменение размера и следующий рендер сбрасывают это состояние.
- Тетрис сравнивает видимое состояние матрицы и LCD-панели, пропуская одинаковые кадры. Смена сегментов, размера и эффект шлейфа сбрасывают кэш; мигание рядов и смена счёта на рекорд учтены отдельно.
- Индикатор паузы и служебные элементы Mario обновляют DOM при изменении значения. Переключение языка принудительно обновляет доступные подписи.
- Меню использует CSS-анимации `transform`/`opacity` и короткие переходы состояний. Дополнительного анимационного JS-рантайма нет; `prefers-reduced-motion` отключает движение меню.

Регрессии кэша проверяются в `tests/render/tetrisScreen.test.ts`, меню и справки — в браузерных тестах. Для повторного измерения запустите Vite, затем:

```bash
CHROMIUM_PATH=/usr/bin/chromium node tools/performance/render.mjs
# При другом порте или базовом пути:
CHROMIUM_PATH=/usr/bin/chromium node tools/performance/render.mjs http://127.0.0.1:5173/
```

Скрипт использует headless Chromium из Playwright, если `CHROMIUM_PATH` не задан. Фиксированный seed обеспечивает повторяемый выбор фигур в последующих замерах.
