# Логотип

Логотип «Crocodile Mario» (надпись и персонаж) предоставлен владельцем репозитория.
Источник и условия использования владелец уточняет сам; в проекте логотип нужен для узнаваемости
в README и в шапке страницы игры.

| Файл | Назначение |
| --- | --- |
| `crocodile-mario-logo-transparent.png` | исходник 2800 × 1240, прозрачный фон (одинаково читается на светлой и тёмной теме) |
| `crocodile-mario-logo-white.png` | исходник 2800 × 1240 на белом фоне |
| `../../public/brand/crocodile-mario-logo.png` | уменьшенная копия 1000 px по ширине для README и страницы (получена из прозрачного исходника) |

Логотип — **фирменная иллюстрация**, а не графика LCD-экрана. Спрайты игры по нему не восстанавливаются:
на экране устройства персонаж — крошечная фигурка в одну ячейку (см. [../visual-spec.md](../visual-spec.md)).
Узнаваемые приметы персонажа, которые стоит учитывать при сверке: шляпа с широкими полями,
круглая голова с зубастой улыбкой, поднятый кулак, шейный платок с кольцом, большие ботинки.
