# Энциклопедия игр

`/encyclopedia?game=tetris` — отдельная страница общего каталога. Кнопка-книга открывает статью игры, выбранной в левой панели. Поиск принимает русские и английские названия; категории, тема, RU/EN и ссылки на разделы работают на мобильных устройствах. Настройка клавиатуры и геймпада остаётся в шестерёнке на главной.

Слева у приставки остаётся одна статичная схема и краткая памятка. Крупный геймплей в энциклопедии — детерминированная запись нашего настоящего движка (`demoClip.ts`), без аудио, игровых рекордов или сетевых партий. Движение можно остановить; reduced motion начинает показ с остановленного кадра. Таймер не рисует скрытый документ или холст вне экрана и удаляется при смене статьи. Для Mario показана оригинальная упаковка; записи матричного движка к его сегментному экрану не применяются.

Каталог отсортирован по **возрастанию редкости** игры (Common → Uncommon → Rare → Ultra Rare → Mobile, затем игры без редкости: Mario, часы, «Ромео и Джульетта»), внутри ступени — по убыванию оценки источников; порядок сохраняется при поиске, выборе категории и смене языка. Редкость — по [Retro Consoles Wiki](https://retroconsoles.fandom.com/wiki/Brick_Game#Games), соответствие игр — [`docs/brick/rarity.md`](brick/rarity.md); значок редкости стоит в списке и в заголовке статьи, у вариаций игры его нет. Значки независимы: **ROM** — правила исследованы по дампу или коду эмулятора, **AI** — авторская логика проекта по описанию и наблюдениям. **α** обозначает прототип с неполными правилами/вариантами, **β** — полный проверенный игровой цикл с продолжающейся доработкой. Процент источников не определяет стадию: лабиринт — 30% / AI / β; приближённый B0202 B01 — ROM / α. У «Пчёлок» происхождение показано отдельно для каждого варианта. Оценки готовности находятся в `src/games/quality.ts`, оценки отдельных native-профилей — в `src/devices/catalog.ts`. Подробнее — [проверка баланса](brick/balance-review.md).

## Источники и оценка

Каталог `src/encyclopedia/catalog.ts` описывает каждую игру отдельно. Пользовательская шкала:

- 30% — правила по словесному описанию.
- 60% — исследование кода симулятора, фото или видео без проверенных правил дампа.
- 90% — проверка по дампу оригинального устройства.
- 100% — независимое подтверждение несколькими источниками.

Это оценка **источников реконструкции**, не результат побитового сравнения прошивок. В статье видны ссылки, тип источника и границы сверки. Наличие одноимённой игры в ROM не считается подтверждением всех правил нашей реализации. В частности, наблюдения E-23/E-88 для родственных аркад перечислены как дополнительные материалы и сами по себе не повышают оценку до 90%. У семейства Tetris отдельно отмечены проверенные общие параметры и непроверенные специальные режимы. Часы ещё не исследованы и не получают численного процента.

## Оригинальные иллюстрации

В `/admin` есть раздел «Энциклопедия игр», общий для всех игр независимо от их назначения приставкам. Выберите игру и вставьте прямую HTTPS-ссылку внешнего хостинга, проверьте предпросмотр, сохраните её в черновик и опубликуйте общей кнопкой под существующим `ADMIN_TOKEN`. Удаление ссылки возвращает статью к стандартным материалам.

Данные хранятся в существующей конфигурации `CONFIG` и сохраняются при экспорте/импорте JSON. SQLite-таблицы рейтинга для иллюстраций не используются: рекорды хранятся отдельно в `LEADERBOARDS`. Новый необязательный раздел совместим со старыми конфигурациями:

```json
"encyclopedia": {
  "snake": { "imageUrl": "https://images.example/original-snake.png" }
}
```

Сервер проверяет HTTPS, длину ссылки и идентификатор игры, запрещает логин/пароль в URL. Изображение загружает браузер, сервер не скачивает внешние адреса. Хостинг должен разрешать прямой показ изображения. При ошибке показывается текст, правила и геймплей остаются доступны. Запрос изображения не передаёт Referer.

Пути `/encyclopedia` и `/encyclopedia/` добавлены в `run_worker_first`; Worker отдаёт основной HTML, а приложение загружает страницу отдельным модулем. Имя Worker, CONFIG, LEADERBOARDS и миграции не изменяются. Для обычного статического хостинга сборка также создаёт `encyclopedia/index.html`: страница открывается в подкаталоге и не требует SPA-переадресаций.
