# Музыка «Ремастер»

Положите сюда готовую запись **`remaster.m4a`** (AAC в контейнере m4a; браузер должен уметь её декодировать — Chrome, Edge, Safari и Firefox умеют).

- Файл грузится один раз, когда в блоке «Звук» на пульте выбрана музыка **«Ремастер»**, и играет по кругу вместо мелодии-пищалки, пока идёт игра. Пауза держит позицию, гибель, конец игры и рестарт останавливают запись.
- Эффекты (прыжок, выстрел и т. д.) остаются пищалкой поверх записи; громкость и кнопка «Звук» действуют и на запись.
- Нет файла, он не декодируется или у браузера нет Web Audio — тихо остаётся оригинальная мелодия.
- Достаточно одного файла: `public/audio/remaster.m4a` (адрес на странице — `audio/remaster.m4a`). Размер лучше держать до нескольких мегабайт (файл отдаётся статикой и грузится целиком).
