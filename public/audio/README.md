# Музыка «Ремастер»

Здесь лежит готовая запись в двух вариантах (≈ 2 мин 55 с, стерео 48 кГц):
- **`remaster.m4a`** — основной, кодек Opus в контейнере m4a (≈ 3,2 МБ): Chrome, Edge и Firefox его декодируют;
- **`remaster-aac.m4a`** — **запасной**, та же запись в AAC-LC 160 кбит/с (≈ 3,6 МБ): AAC декодируют все браузеры, в том числе Safari, у которого поддержка Opus в MP4 зависит от версии (без запасного варианта на таком iPhone звучала бы прежняя мелодия, и выбор «Ремастер» казался бы кнопкой, которая ничего не делает).

**Порядок загрузки** (`remasterSources` в `src/audio/remaster.ts`): браузер, у которого `canPlayType('audio/mp4; codecs="opus"')` непустой, начинает с Opus; пустой ответ (Safari старых версий) — сразу с AAC, чтобы не качать файл, который не декодируется. Если выбранный файл не загрузился или не декодировался, пробуется второй; если не подошёл ни один — звучит оригинальная мелодия, а на кнопке «Ремастер» виден статус (⚠ и подсказка; пока файл грузится — мерцание или «…», `data-remaster` на `#music`). Запасной файл получен из основного: `ffmpeg -i remaster.m4a -vn -c:a aac -b:a 160k -ar 48000 -movflags +faststart remaster-aac.m4a`. **Проверка:** AAC-версия измерена той же сверкой громкости (−14,2 LUFS без усиления, `TRACK_GAIN = 0,38` не выше допустимых 0,398); декодирование проверено ffprobe, а в браузерном тесте — только там, где браузер умеет AAC (Chromium, который ставит Playwright, собран без AAC и его не декодирует; на настоящих Chrome, Edge, Firefox и Safari AAC работает).

Если заменяете запись, замените оба файла (запасной получается командой выше).

- Файл грузится один раз, когда в блоке «Звук» на пульте выбрана музыка **«Ремастер»**, и играет **по кругу** вместо мелодии-пищалки, пока идёт игра. Пауза держит позицию, гибель, конец игры и рестарт останавливают запись.
- **Петля.** В конце записи ≈ 1,1 с тишины; воспроизведение зацикливается на «хвосте без тишины» (`loopEndOf` в `src/audio/remaster.ts` обрезает хвост по уровню 0,001 с запасом 50 мс), так что музыка идёт без паузы перед повтором. Сам файл не правится.
- **Громкость не выше оригинала.** Интегральная громкость записи — −14,1 LUFS, оригинальной мелодии при громкости ползунка 100 % — −22,2 LUFS. Запись идёт через собственный регулятор `TRACK_GAIN = 0,38` (−8,4 дБ → ≈ −22,5 LUFS, чуть тише мелодии), ползунок громкости и кнопка «Звук» действуют на неё так же, как на мелодию. Пересчёт при смене записи: `node --experimental-strip-types tools/audio/loudness.mjs [путь/к/файлу]` (нужен ffmpeg) — печатает максимально допустимый `TRACK_GAIN`.
- Эффекты (прыжок, выстрел и т. д.) остаются пищалкой поверх записи, пока выбран «Ремастер» — вдвое тише (`SFX_REMASTER_GAIN = 0,5`, −6 дБ): ровная запись маскирует их хуже, и резкие прямоугольные волны выпирали. Ползунки «Звук» (эффекты) и «Музыка» (запись, множитель `TRACK_GAIN`) независимы под «Ремастер» и связаны под «Оригинал».
- **Переключение на лету.** «Оригинал» ↔ «Ремастер» меняется сразу, пока играет мелодия: запись вступает с позиции «время от старта мелодии» (`RemasterTrack.seek`, часы — `MelodyPlayer.elapsed`), пищалка подхватывает по тем же часам; поэтому «то же место» приближённое (у записи ≈ 175 с, у мелодии-пищалки круг ≈ 10,9 с). Повторный `setMusic` с тем же значением ничего не перезапускает (включение сегментов, возврат на вкладку); запись, догрузившаяся позже выбора, тоже подхватывает звучащую мелодию.
- Нет файла, он не декодируется или у браузера нет Web Audio — тихо остаётся оригинальная мелодия (`data-music-source` на игровой области показывает, что звучит на самом деле).
- Заменить запись: положить другой файл с тем же именем `public/audio/remaster.m4a` (адрес на странице — `audio/remaster.m4a`). Файл отдаётся статикой и грузится целиком — лучше держать несколько мегабайт.
