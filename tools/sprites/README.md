# Спрайты клетки по макрофотографиям экрана

Клетка LCD (блок, герой, значки жизни, снаряд-сердечко) перерисована по четырём макрофотографиям экрана оригинала; подробности и допущения — в [docs/visual-spec.md](../../docs/visual-spec.md#1-модель-экрана-и-спрайты-клетки).
Нужны Python 3, `opencv-python` и `numpy`. Сами фотографии в репозиторий не входят (файлы владельца).

| Скрипт | Что делает | Результат |
| --- | --- | --- |
| `extract_block.py фото03 фото10 фото15 фото12 block-gaps.png` | выпрямляет группы блоков с фото (гомография по четырём углам группы), уточняет каждую клетку по среднему (ECC), усредняет 18 клеток, обрезает по тёмному прямоугольнику и бинаризует | `block-gaps.png` — маска 480 × 416 (клетка 120 × 104 в масштабе 4×), белое там, где свет |
| `compose_atlas.py` (из корня репозитория) | собирает из маски кадры `cell.obstacle`, `cell.all_on`, `cell.player`, `cell.ghost`, значки жизни в `public/graphics/lcd/lcd_atlas.png` и снаряд `lcd_heart.png` | перезаписывает эти кадры, остальные не трогает |

Если фото нет, достаточно `compose_atlas.py`: маска лежит в репозитории.
