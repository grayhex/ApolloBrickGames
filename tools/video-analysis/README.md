# Анализ видео фрагмента (наблюдения, не правила оригинала)

Скрипты, которыми получены числа в [docs/video-observations.md](../../docs/video-observations.md). Видео в репозиторий не
входит (файл владельца `Video_Project_3.mp4`, 1280 × 720, 30 кадров/с); положите его рядом как `in.mp4`.
Нужны Python 3, `opencv-python`, `numpy` и `ffmpeg`. Запуск — из каталога с `in.mp4`, по порядку:

| Скрипт | Что делает | Результат |
| --- | --- | --- |
| `stabilize.py` | ORB + RANSAC-гомография каждого кадра к эталонному (кадр 15), выпрямление LCD-поля в 520 × 284 | `lcd_full.npy`, `lcd_small.npy`, `stab.json` |
| `cells.py` | сетка 13 × 6 (шаг 37,9 × 37,0 px, начало 15, 58), «чернильность» клетки | функция `ink_matrix` |
| `timeline.py` | матрица занятости клеток по кадрам и список изменений (`#` — блок, `+` — частично, `.` — пусто) | `ink.npy`, текст в stdout |
| `hero.py` | шаблон героя (кадры 136–139, клетка (5,1)) и поиск по клеткам (NCC) | `hero_resp.npy`, `hero_tpl.png` |
| `audio_leds.py` | проверка звуковой дорожки (RMS) и яркости трёх светодиодов по кадрам | текст в stdout |

Четыре угла LCD в эталонном кадре заданы вручную в `stabilize.py` (`quad`) — для другого видео их нужно переставить.
Точность по времени — ±1 кадр (±33 мс).
